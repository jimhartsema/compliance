# Getting access

If you already have access to the dashboard, you may skip this step and proceed to the next. If not, please continue reading.

Access to our dashboard currently requires contacting our sales team directly to set up an account. Currently we only support **professional** and **enterprise** tier clients. We are committed to expanding access to include a wider audience soon and will keep this page updated with the latest developments.

## Requesting access

To initiate the onboarding process at Ver.iD, you need to directly contact our sales team as we are currently manually onboarding new clients due to a comprehensive compliance and assessment process. Unfortunately, self-onboarding is not available yet; however, we are actively developing this feature and aim to release it as soon as possible.

All new client requests must undergo an extensive [relying party assessment](../compliance/clients/introduction.md), which verifies your organization's suitability to handle personal and, in some cases, sensitive information like national security numbers wherefor you require a legal basis to do so. You can start this process by sending an email to `sales@ver.id`. This email should contain atleast your organizational name, a contact person, the person that should receive an invitation mail and a small description on the use-case and if sensitive attributes are required.

## Access the dashboard

After your organization is verified and the relying party assessment is completed, you will receive an invitation email that allows you to set a new password for your account. While you can also log in using a supported decentralized identity app, setting up using a password is initially required. You can access the dashboard directly by clicking [here](https://spas.nebula.ver.id) or press the login button on our primary website.

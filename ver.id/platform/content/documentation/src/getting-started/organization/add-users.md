# Add your users

If you are the primary user responsible for creating flows, you may skip this step and proceed to the next. If not, please continue reading to learn how to add more users and configure their role and subsequent access rights to your organization in our dashboard.

In the `Settings` menu on the left side of the dashboard, there is a section titled `Users`. This section allows you to add additional organization users, such as developers, compliance or other employees that requires access to the dashboard to see and edit flows. You can add multiple users, each with their own role. The maximum number of users depends on your organization's current billing plan. In the playground plan (free plan), the default billing plan, you can only have 10 users in total.

## Create a user

To create a new user, click the `Create user` button found in the `Users` section. This will open a dialog modal prompting you to enter the details of the new user you wish to add. After entering the details, click `Create user` within the modal to proceed to the dedicated user page.

The new user will receive an invitation e-mail that allows the user to set a new password for their account. Please note that this invitation link is set to expire. If expired, you can resend the e-mail via the dedicated user page.

### Roles

We offer two user roles:

- **Owner**: This is the primary role for most users, granting comprehensive control over the dashboard. Owners can modify settings, create flows, add new users, and generate API keys.

- **Auditor**: This role is restricted to read-only access, ideal for compliance monitoring or for users who need to review configurations without making changes.

## Manage users

In the dedicated user page, the 'Owner' of the organisation can manage the users who have access to the dashboard. If needed, changes can be made to their First Name, Last Name, Role and Logo by selectin the `Edit` button.

If required, the user can be 'Blocked' by selecting the `Block` button or 'Removed' via the `Remove` button. Note that 'Block' can be undone, and 'Remove' cannot be undone.
